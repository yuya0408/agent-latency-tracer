# 文書検索の文書

`retrieve_documents`(文書検索のツール)が検索する文書。社内規程集にあたる文書として、公開されているひな形と法令を使う。
`chunks.jsonl`は1行が1条で、`scripts/build_corpus.py`で作り直せる。AWSでは各条をTitan Text Embeddings V2で埋め込み(`scripts/embed_corpus.py`、ベクトルはコミットしない)、RDSのpgvectorに入れて検索する(`scripts/load_pgvector.py`)。

| 国家公務員等の旅費に関する法律 | 2025-04-01施行 | e-Gov法令検索 https://laws.e-gov.go.jp/law/325AC0000000114 |

## 加工したこと

厚生労働省の2つの文書は、次のように編集・加工している(内容を国が作成したものではない)。

- 条ごとに切り出し、各条の先頭に文書名・条・見出しの1行を付けた
- 厚生労働省による解説・参考の部分を除いた
- 規定例が複数の案を示している箇所(〔例２〕〔例３〕、《…例》)は、最初の案だけを残した
- 附則を除いた。表は、セルの文字を行ごとに並べた

法令も、本則の条ごとに切り出し、附則と削除された条を除いている。

## 利用条件

このフォルダの文書には、リポジトリのコードとは別の条件がかかる。

- 厚生労働省の2つの文書は、[厚生労働省ホームページの利用規約](https://www.mhlw.go.jp/chosakuken/index.html)
  (公共データ利用規約(第1.0版)に準拠)に従う。利用するときは出典を記載し、編集・加工した場合はその旨も記載すること
- 法令は、著作権法第13条第1号により、著作権の目的とならない
